About This Project

Project Overview
Deep Learning-Based Brain Tumor Detection, Segmentation and Diagnostic Support System

A fully integrated AI pipeline that accepts brain MRI scans and delivers automatic tumor classification, pixel-level segmentation, and explainable heatmaps — all accessible through this web interface.

Research Gap Addressed

No single existing paper combines all four of: pixel-level segmentation, 4-class tumor classification, visual explainability (Grad-CAM), and a deployable web interface. This project bridges that gap.

Algorithm Pipeline
  1. Preprocessing — resize to 224×224 / 256×256, normalize, skull-strip
  2. U-Net — pixel-wise tumor boundary segmentation
  3. EfficientNetB0 — 4-class tumor type classification
  4. Grad-CAM — visual heatmap explaining the classification
  5. Flask + SQLite — web dashboard with stored diagnostic history
